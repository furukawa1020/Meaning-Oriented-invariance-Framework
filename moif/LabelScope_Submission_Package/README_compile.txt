Compilation Instructions for LabelScope:

1. This manuscript uses the standard IEEEtran class (included).
2. The bibliography is embedded within the .tex file using the 	hebibliography environment; no separate .bib or .bbl files are required.
3. Compile using: pdflatex labelscope_manuscript.tex (run twice for cross-references).
4. Figures are included as .png and .pdf files in the same directory.
